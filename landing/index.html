A folder you can search again

Built for the pile of unnamed snips that collects after a week of debugging.

  • Search by the screen, not the clock

    Names describe the UI. An Auth0 error, a Figma export dialog, a failing test become filenames you can type in Explorer.

  • Nothing leaves the laptop

    Gemma runs through Ollama. The image is read locally. There is no account, no upload, and no API key.

  • Preview before a single rename

    Dry run shows the slug and a one line reason. Rename only when the name looks right. Collisions get a numeric suffix.

  • Catches the default Windows names

    Scan looks for Screenshot, Screen Shot, and Cuplikan layar. Point it at Pictures\Screenshots, or any folder you pick.

Three steps, then the folder is searchable

  1. 01

    Point it at Screenshots

    On first launch Snipname opens %USERPROFILE%\Pictures\Screenshots. Browse if your snips live somewhere else.

  2. 02

    Check Ollama, pick Gemma

    The app lists models already pulled. A vision Gemma such as gemma3:4b is enough. If the list is empty, pull one and check again.

  3. 03

    Scan, dry run, rename

    Scan finds unnamed png, jpg, and webp files. Dry run proposes a kebab case stem. Rename writes the file when you say so.

Questions

Does the screenshot leave my computer?

No. Snipname calls Ollama on 127.0.0.1:11434 from the Rust side of the app. Gemma reads the image locally. There is no cloud model and no telemetry account.

Which filenames does Scan pick up?

Files whose names start with Screenshot, Screen Shot, or Cuplikan layar, with a png, jpg, jpeg, or webp extension. Already named files are left alone.

What does a generated name look like?

English kebab case, three to eight words, no date, no extension in the stem. The model also returns a one sentence reason, shown under the proposed name so you can reject a bad read.

Can a rename overwrite a file I already have?

No. If auth0-login-error.png exists, the next one becomes auth0-login-error-2.png, then 3, and so on.

Why is the download a zip, not a single installer?

GitHub Actions stores the Windows bundle as one artifact. The zip holds snipname_0.1.0_x64-setup.exe (NSIS), the MSI, and snipname.exe if you want to run it without installing.

Do I need a GitHub login to download?

No. The download button fetches the newest successful Actions artifact and sends the zip directly. GitHub login is only needed if you open the build log instead.

Windows SmartScreen warns about the installer.

The build is unsigned on purpose for this demo. SmartScreen will flag an unknown publisher. Install only if you trust this repository.

Which model should I pull?

Any vision capable Gemma that Ollama lists. gemma3:4b is the default the app suggests. Check Ollama in the app after the pull so the model appears in the dropdown.
